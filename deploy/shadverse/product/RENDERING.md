# SHADVERSE JARVIS · Living mechanical identity

The final Creator direction specifies a completely robotic head. The shipped portrait is an original 47-part assembly. Its pressure shell supports a segmented optical canopy, paired emissive sensors, machined brow plates, cheek guards, acoustic louvres, rotary joints and a neck coupling. Eight material identifiers distinguish the frame, armour, optical glass, emitters, grille and chrome. The authoring script exports the chassis surface and up to 56,000 particle sites.

## References and verification

The Creator’s first inline reference shows a frontal silhouette made legible by violet light and particle density. The second shows a tilted handset with cyan traces, luminous controls and multiple levels of instrumentation. The portrait uses depth-tested particles and the monitoring screen plots measured browser intervals. Both reference pictures stay in the conversation.

The brief identifies the sources as Dogstudio / DEPT Pioneer and Neuradigi. The original studio and Awwwards pages returned HTTP proxy errors in this environment, including on a permitted retry. The exact projects’ shaders, datasets and performance characteristics could not be independently verified. Access to Active Theory and Resn was also unavailable.

## Dependencies, assets and reproduction

- Runtime rendering uses browser WebGL2 and Web Audio. Two indexed/point drawing passes, typed buffers and GLSL handle the chassis and its particles. No new JavaScript package is required. Instanced billboards, Three.js and React Three Fiber were considered. Point sprites fit the required primitive, and direct WebGL2 integrates into the existing DOM application.
- The geometry authoring script uses local Blender and NumPy. Regenerate with `blender -b -P art-tools/model-chassis.py` from this directory. Blender is a build-time tool. The distributed binaries contain original vertices, normals, material identifiers and sample positions. SHADVERSE ©.
- The liquid-glass environment, normal map, chassis, shaders and interface are original project assets. The browser applies a displacement filter to an offset image of the environment. Hover lighting and the refractive border affect decorative layers independently of readable text. A browser that omits the displacement filter retains the translucent surfaces and edge lighting.
- The prerecorded English test sentence was synthesized offline using FFmpeg’s Flite source and the CMU `kal` voice. Only the generated waveform is bundled. No voice model or synthesis executable ships with the app. [Flite source and license](https://github.com/festvox/flite)
- The existing Vazirmatn and Space Grotesk fonts are self-hosted with their OFL notices. OpenClaw retains its MIT attribution. The preview embeds the font notices. The visual research links above are references only.

## Runtime boundaries

The renderer interpolates states without replacing the canvas. In listening mode, actual input amplitude and frequency pull particles inward and backward. In sample playback they move outward and forward. Manual listening/speaking pose selection is labeled as a demonstration. The microphone is disconnected from the output, and its tracks stop on explicit stop, state change, page navigation, tab hiding and sign-out. The sample ends automatically. Live model output and speech recognition require later integration.

The quality controller caps pixel density and draw frequency, reduces point count after sustained frame delays, and selects a lower tier on software rasterizers. Reduced motion holds a static pose. Hidden tabs suspend drawing, and loss or absence of WebGL switches to a Canvas 2D projection of the same mechanical geometry. The mobile performance report distinguishes browser callbacks from actual renderer submissions. Hardware frame presentation, battery draw and physical-device thermals are unverified.

Workspace records are scoped to page memory and are cleared on sign-out. The account directory is served by the existing authenticated Creator endpoint. Browser instrumentation reports the current tab. Production memory, subscriptions, model routing and deployment remain separate from this visual review.
